Політика конфіденційності — Цікаві факти💡

Останнє оновлення: жовтень 2026

Ця політика пояснює, які дані збирає та як використовує застосунок Цікаві факти💡, що публікує відео на TikTok-акаунті @cikavi_fakty_ua.

Які дані збираються

Застосунок отримує через TikTok OAuth лише мінімально необхідні дані:

  • Токен авторизації (access token / refresh token) для публікації відео від імені акаунту, який надав дозвіл
  • Базову публічну інформацію профілю, необхідну для роботи API публікації (наприклад, дозволені рівні приватності постів)

Застосунок не збирає й не зберігає особисті повідомлення, контакти, дані інших користувачів TikTok чи будь-яку інформацію поза тим, що безпосередньо потрібно для публікації відео.

Як використовуються дані

Токени авторизації використовуються виключно для публікації автоматично згенерованих відео на акаунті, який особисто надав дозвіл. Дані не продаються, не передаються рекламодавцям і не використовуються для жодних цілей, окрім зазначеної.

Де зберігаються дані

Токени авторизації зберігаються як зашифровані секрети в інфраструктурі GitHub Actions, доступ до яких має лише власник репозиторію. Дані не зберігаються на сторонніх серверах поза цією інфраструктурою.

Видалення доступу

Власник акаунту може в будь-який момент відкликати доступ застосунку через налаштування TikTok (Settings → Security → Manage apps), після чого застосунок втрачає можливість публікувати контент.

Privacy Policy — Цікаві факти💡

Last updated: October 2026

This policy explains what data Цікаві факти💡 collects and how it is used. Цікаві факти💡 publishes videos to the TikTok account @cikavi_fakty_ua.

What data is collected

Through TikTok OAuth, the app receives only the minimum data required:

  • An authorization token (access token / refresh token) used to publish videos on behalf of the account that granted permission
  • Basic public profile information needed for the posting API to function (e.g. available post privacy levels)

The app does not collect or store direct messages, contacts, other TikTok users' data, or any information beyond what is directly required to publish videos.

How data is used

Authorization tokens are used solely to publish automatically generated videos to the account that personally granted permission. Data is not sold, not shared with advertisers, and not used for any purpose beyond what is described here.

Where data is stored

Authorization tokens are stored as encrypted secrets within GitHub Actions infrastructure, accessible only to the repository owner. No data is stored on any third-party servers outside this infrastructure.

Revoking access

The account owner may revoke the app's access at any time via TikTok settings (Settings → Security → Manage apps), after which the app loses the ability to publish content.

Contact

For privacy-related questions, reach out via the Telegram channel @cikavi_fakty_ua.
